# 重排：已实现能力及生产待办

记录日期：2026-10-30。当前实现用于学习和分阶段验证，尚未作为生产方案交付。重排只能调整 dense 已召回的候选顺序，不能替代召回。

## 已实现

| 能力 | 当前做法 | 边界 |
| --- | --- | --- |
| 两阶段检索 | dense 先取 `candidate_k=20`，再由本地 CrossEncoder 重排并交付 `top_k=5`；两个数量都可配置，且要求 `top_k` 不大于 `candidate_k`。 | 候选不足时返回实际数量；重排无法找回 dense 前 20 之外的内容。 |
| 本地重排模型 | 用 `sentence-transformers` 的 `CrossEncoder` 加载 `BAAI/bge-reranker-v2-m3` 本地快照，CPU 推理，`local_files_only=True`、`trust_remote_code=False`，不联网下载。 | 只校验目录存在，没有像 embedding 那样核对模型版本摘要；模型文件变化不会被发现。 |
| 分数与排名分离 | 保留 dense 原始排名和相似度分数，另存重排分数和新排名；并列时按原候选顺序稳定排序。 | 两类分数来自不同模型，不能直接比较；重排分数也不能跨查询当作置信度。 |
| 来源保留 | 重排基于候选对象生成新结果，只改动排名和重排分数；正文、文件名、路径和物理页码沿用索引中的值，来源状态在每次查询时按当前文件重新核对。 | 重排不重新核验源文件；源文件缺失或内容变化时，候选仍会返回并把 `provenance_complete` 设为 `False`，不会被过滤。 |
| 失败处理 | 模型目录缺失、依赖缺失、分数数量不一致、非有限分数都会明确报错；不静默退回 dense。 | 用 `--dense-only` 时才使用纯 dense 顺序，输出会标明实际模式。 |
| 评测入口 | `retrieval evaluate` 用带答案页标注的问题集统计候选召回、dense 名次和重排名次，问题集与文档共用 `questions.json`。 | 名次命中只说明答案页被检索到，片段是否支持答案仍需人工核对。 |

运行命令见 [README](../../README.md)。三次查询的人工对照见 [重排实验记录](../experiments/reranking.md)，固定问题集的结果见 [检索评测记录](../experiments/retrieval-eval.md)。

## 生产场景尚未实现或验证

| 问题 | 影响与后续方向 |
| --- | --- |
| 重排质量 | 三条查询中一次改善、两次变差；固定问题集上 dense 前 5 命中 7/7，重排 6/7。当前不能声称两阶段检索优于 dense，也不应默认启用。 |
| 清单页偏好 | 重排会把按时间罗列条目的“清单页”（第 448–451、455 页）排到前面，它们在字面上与“怎么办”高度重合，主要是转引其他章节的索引，具体依据仍要回到对应章节。部分条目也含 12333、1 年时效等数字，不能简单按页面类型排除；需要更细的片段分类、元数据标记或针对性负样本，尚未实现。 |
| 候选召回上限 | 重排只处理 dense 前 20；`labor-unpaid` 的答案页在候选内但被挤出前 5。提高候选数、引入 hybrid/lexical 召回或按来源过滤都未实现，也未比较成本。 |
| 模型选型与版本 | 只验证了 `bge-reranker-v2-m3`，没有与更小模型或其他语言模型做同输入对照；重排模型快照没有内容摘要校验，换机器时无法确认版本一致。 |
| 输入长度 | CrossEncoder 有自身最大输入长度，长片段可能被静默截断；当前没有显式设置、记录或报告截断行为。 |
| 阈值与资料不足 | 书外问题的最高重排分 0.0065，文档内为 0.78–0.97，但样本只有一题，不能据此设阈值；程序只在候选全部被来源和正文校验过滤时输出“未找到可交付的检索结果”，没有基于分数的低相关判定。 |
| 性能与成本 | 未记录重排耗时、吞吐和内存；CPU 推理依赖 `CrossEncoder.predict` 的默认批处理，未显式设置 `batch_size`，也没有 GPU、缓存、并发或吞吐测量，无法评估生产延迟。 |
| 评测方法 | 标注是页级而非片段级，问题按书中标题措辞拟，样本少且只有一份 PDF；可能高估效果。需要片段级相关性标注、Recall@K/MRR、真实问法和第二份文档。 |
| LlamaIndex 集成 | 当前直接调用 `CrossEncoder`，没有通过 LlamaIndex `NodePostprocessor`；后续组合其他后处理、回调或可观测能力时需要重新设计接入口。 |
| 可观测性与恢复 | 没有记录每次重排的候选数、耗时和模型版本；模型加载失败以外的运行时异常没有重试或降级策略。 |

以上是待实现或待验证的方向，不代表已经发生线上故障，也不预设具体模型或基础设施选型。
