# 切片：已处理问题与待验证风险

记录日期：2026-10-29。本文针对当前 PDF 加载和切片实现；索引、检索等后续模块尚未完成。

## 已处理

| 问题 | 当前处理方式 | 边界 |
| --- | --- | --- |
| 页边界切断上下文 | 合并来源元数据和元数据排除设置一致的连续页面后切片，可生成跨页片段。 | 设置不一致时断开；重叠是上限，不能保证每个观点完整。 |
| 不连续内容被拼接 | 不同文件、缺页和空页处断开。 | 仍需检查 PDF 实际阅读顺序。 |
| 重复文本标错页码 | 切片合并时记录原文字符位置，以位置和页面区间计算来源，不依赖反向搜索文本。 | 已测试重复文本在有、无重叠时的页码或位置；不代表覆盖所有文档。 |
| PDF 页码字段冲突 | 使用 `page_numbers` 列表作为 PDF 页码来源；展示时从列表生成文字。缺失或无效页码会报错。 | 非 PDF 定位继续使用 `source_location`。 |
| 元数据影响正文切片预算 | 切片时暂时排除元数据，之后恢复调用方的排除设置；正文长度按 LlamaIndex 默认 tokenizer 计算。 | 不保证最终模型输入符合目标模型的 token 限制。 |

当前实现包含切片参数、来源信息校验和相邻节点关系。验证命令及使用方式见 [README](../../README.md)；参数对照和真实 PDF 观察见 [切片实验记录](../experiments/chunking.md)。使用者仍需对照原 PDF 检查，并确认本模块结果。

## 未处理或待验证

| 问题 | 影响与后续方向 |
| --- | --- |
| 文档身份与版本 | `source_id` 由路径生成：同路径文件内容更新时标识不变，文件移动后标识改变。索引阶段须定义内容版本、增量更新和删除策略。 |
| PDF 解析质量 | 当前使用 `pypdf` 的文本层；扫描件可能为空，多栏、表格、图片、页眉页脚和阅读顺序可能处理不佳。根据实际文档评估布局解析或 OCR，并核对原页。 |
| 模型输入限制 | 实际模型的 tokenizer、元数据和上下文上限可能与当前正文 token 统计不同。接入模型时须检查完整输入并预留空间。 |
| LlamaIndex 内部接口 | 位置适配器依赖 `_Split` 和 `_merge` 等内部实现。锁定当前依赖版本，升级时重新验证文本、偏移和重叠，并评估稳定的公开接口；内部接口不等于已弃用。 |
| 大文档和并发 | 当前合并连续页面文本，并为片段遍历页面区间；尚未做资源、性能和并发测试。按预期规模压测后，再评估分批及区间查找方案。 |
| 切片与检索质量 | 尚未依据固定问题评估召回、上下文完整性和成本。对照不同参数与实际文档，记录人工判断；默认参数不代表生产最优。 |
| 节点持久化 | 节点 ID 每次运行重新生成，索引阶段需明确稳定标识、来源关联和更新语义，不能依赖运行时 ID。 |
| 文档结构与噪声 | 页眉、页脚、目录点线、表格等可能占据切片预算或干扰检索。需结合文档类型检查并评估处理方式，不能假设所有文档结构相同。 |

这些待办是生产场景的风险和后续验证方向，不代表已完成实现或已测得发生概率。
