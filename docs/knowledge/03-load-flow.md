# 文档加载：已处理问题与待验证风险

记录日期：2026-10-29。本文针对当前 PDF 加载实现，生产场景的风险需要结合实际文档验证。

## 已处理

| 问题 | 当前处理方式 | 边界 |
| --- | --- | --- |
| 来源定位 | 每页保留文件名、绝对路径、来源标识和从 1 开始的物理页码 `page_numbers`。 | 路径标识不代表文件内容版本。 |
| 选择页面 | 可指定包含两端的物理页码范围，并校验范围和文件路径。 | 加载入口目前只支持 PDF。 |
| 空页和页面异常 | 逐页区分成功、空文本和失败；单页失败不阻止检查其余页面。命令行显示状态，存在失败时返回非零状态。 | 非空仅表示提取到了文本，不代表内容完整或顺序正确。 |
| LlamaIndex 加载入口 | `load_data` 返回文档列表；存在解析失败页时抛出异常。 | 异常列出失败页码，但未包含各页具体错误原因；空文本页仍会返回，调用方须自行检查。 |

运行方式见 [README](../../README.md)。项目要求人工对照 PDF 抽查首页、中间和末尾的可提取文本页面，并记录异常；自动测试不能替代人工验收。

## 未处理或待验证

| 问题 | 影响与后续方向 |
| --- | --- |
| 扫描件与图片文字 | 当前只提取 PDF 文本层，没有 OCR。扫描页与真正的空白页都可能显示为空文本；按实际文档评估 OCR。 |
| 阅读顺序与结构 | 多栏、表格和图片说明可能顺序错误或丢失结构。非空页面会标记为成功；需对照原 PDF 检查质量，必要时评估布局解析。 |
| 页眉、页脚和脚注 | 当前原样保留，可能干扰切片与检索。清洗应先在真实文档上检查候选内容，避免误删正文或脚注，并保留来源追溯能力。 |
| 文档身份与版本 | `source_id` 由绝对路径生成；原路径内容更新不会改变 ID，文件移动则会改变 ID。进入索引模块前需确定内容版本与更新、删除策略。 |
| 加密或损坏的 PDF | 未提供密码输入和专门错误分类；文件打开异常向上抛出，命令行报告失败。尚未覆盖相关测试。 |
| 大文件与资源限制 | 尚无文件大小、页数、处理时间或内存限制，也没有大文件或并发压测；应按实际使用规模验证。 |
| 失败原因传递 | `load_pages` 保留页面异常文字，`load_data` 只汇总失败页码；后续处理需要更具体的诊断信息。 |
| 测试覆盖 | 已有空页、单页失败、无效范围和真实 PDF 测试；扫描件、复杂排版、加密或损坏文件及大文件尚未覆盖。 |

这些待办是风险和验证方向，不表示已经实现，也不表示已测得发生概率。
