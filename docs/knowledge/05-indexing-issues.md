# 向量化与索引：已实现能力及生产待办

记录日期：2026-10-29。当前实现用于学习和分阶段验证，尚未作为生产方案交付。

## 已实现

| 能力 | 当前做法 | 边界 |
| --- | --- | --- |
| 本地向量化 | 使用 LlamaIndex `HuggingFaceEmbedding`，从指定的本地 Hugging Face 缓存快照加载模型，在 CPU 上逐个转换切片正文。 | 示例模型为 `BAAI/bge-small-zh-v1.5`；不发送正文到外部模型服务。模型资源必须已在本地。 |
| 模型输入检查 | 使用加载后模型的 tokenizer、文本前缀和长度上限检查输入，超长时拒绝构建。索引默认切片参数为 384 / 64，单位是 LlamaIndex tokenizer 的 token。 | 该默认值基于当前 PDF 和模型的实跑，不保证其他文本或模型不超限；逐片检查仍然必要。检查依赖当前版本 `HuggingFaceEmbedding` 的内部模型接口，升级依赖时须重新验证。 |
| 本地向量存储 | `VectorStoreIndex` 默认使用 `SimpleVectorStore`，持久化到索引目录中的 JSON 文件；向量保存在 `default__vector_store.json`。 | 这是本地文件存储，尚未接入独立的向量数据库服务。 |
| 来源和版本记录 | 文档库保留片段正文与来源；`manifest.json` 记录模型快照摘要、维度、切片参数、文档路径和内容摘要等信息。 | 片段可通过 ID 回查；路径变化不会自动更新，回查时会提示来源缺失或内容变化。 |
| 受控重建 | 构建到临时目录后原子发布，目标已存在时拒绝覆盖；重复片段 ID 被拒绝。 | 不支持追加或更新，需在新目录中传入全部文档重新构建。原子发布目前支持 macOS 和符合条件的 Linux。 |
| 失败与覆盖情况 | 报告向量化数量和发布状态，记录空文本页并在概览、回查时提示。 | 构建前尚未生成切片时，未处理数量无法确定；空文本页仍需人工判断。 |

运行命令见 [README](../../README.md)。真实 PDF 第 4–5 页的构建和回查，以及全文构建结果见 [索引实验记录](../experiments/indexing.md)；这些运行不代替用户对照原文的验收。

## 生产场景尚未实现或验证

| 问题 | 影响与后续方向 |
| --- | --- |
| 向量数据库 | 尚未接入 Chroma、Milvus 等数据库，也没有数据库的部署、备份、恢复或运维方案。需要时根据规模和运行环境选择存储，并重新验证写入、加载及来源关联。 |
| 规模与性能 | 当前逐片向量化，节点及向量在构建过程中保留于内存。当前 PDF 全文实跑耗时约 56.3 秒、索引约 41.1 MB；内存、加载耗时及检索性能尚未测量，也未进行目标规模压测。需测量后再评估批处理和存储方案。 |
| 增量更新 | 未实现追加、删除、版本切换或在线更新；文档变化时需受控重建。生产场景需明确更新、去重、失败恢复及并发写入语义。 |
| 查询与模型兼容 | 当前没有语义检索入口；配置比较函数尚未接入查询流程。后续查询须检查模型及索引兼容性，模型或切片配置变化时重建或隔离索引。 |
| 查询指令 | 使用本地快照路径时，LlamaIndex 不会根据标准模型名自动识别 BGE 的中文查询指令。检索阶段须按所选模型显式配置并验证查询编码。 |
| 检索质量 | 尚未用固定问题和人工核对评估召回；向量化成功不代表检索质量达标。需使用相同输入比较模型和切片配置。 |
| 数据保护与运维 | 尚未实现生产环境所需的访问控制、监控、容量管理和故障恢复；索引文件包含向量、正文及来源信息，部署时需按数据敏感程度保护。 |
| 验收范围 | 全文、第二份 PDF、文档内容和路径变化的人工验收，以及长时间运行和故障场景仍待验证。 |

上述事项是待实现或待验证的方向，不代表已经发生故障，也不预设具体生产规模或数据库选型。
